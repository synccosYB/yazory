# Yazory application audit — October 6, 2026

Audited the GitHub `design/case-workspace` snapshot `4db37a7` in an isolated
checkout. Corrections are on `audit/application`. No production records were
changed and no production deployment was performed.

This audit covers source inspection, isolated application tests, and browser
checks against fictional records. It does not certify production integrations.

## Validation

Final Python suite: **629 passed, 0 failed**, in 239.52 seconds.
Signed-in browser suite: **26 passed, 0 failed, 0 skipped**, in 16.3 seconds.
The JavaScript imported-person picker check passes. Python compilation,
JavaScript syntax checks, and `git diff --check` pass.

The Python suite reports 452 existing SQLAlchemy deprecation warnings from
partial import flushes (`Session.flush(objects=...)`). These are dependency
maintenance debt; their removal remains outside the completed workflow fixes.

Browser checks use a signed-in organization-admin fixture and fictional local
SQLite data. `VISUAL_STORAGE_STATE` accepts an authenticated Playwright storage
state for reproduction; `VISUAL_BROWSER_EXECUTABLE` optionally selects a local
Chromium executable. Do not commit authentication state.
The layout suite covers Overview, Families, a case, Communications and
Operations at 1440, 390 and 720 CSS pixels. The 720-pixel check approximates the
layout width of 200% desktop zoom; it is not a native browser zoom check.
Additional checks cover Hebrew/Yiddish RTL, supporter search, applicant-folder
navigation, nested financial/expense links, child forms, and saving/reopening
a person through JavaScript. HTTP error/sign-in pages do not count as coverage.

The original source inventory contained 248 routes. A 376-URL navigation crawl
had no 404 or 500 responses, but many URLs redirected or denied access; that
crawl is not evidence of completed authenticated workflows.
