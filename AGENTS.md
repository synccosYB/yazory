# Yazory development requirements

- Develop in the GitHub-backed workspace. Never use Replit Agent for development.
  Replit is only for shell-based pull/push, runtime configuration and deployment.
- Every user-facing change must ship together in English, Hebrew and heimish
  Yiddish. Preserve the owner's current Yiddish wording until corrected.
- Use the official helping-hands logo and navy/gold theme across all languages,
  screens, letters and receipts. English is LTR; Hebrew and Yiddish are RTL.
- Design desktop pages to fit the available window without unnecessary scrolling.
  Use short sequential form steps, profile tabs and list pagination. Keep actions
  visible. Never hide inaccessible content with overflow clipping; retain usable
  reflow for small screens and zoom.
- New intake fields and provider/account entries start blank. Add custom utility,
  grocery, mosdos and assistance records on demand. Preserve leading zeros in
  account numbers and use integer cents for monetary storage.
- Protect household budgets and account numbers using the existing family and
  staff permissions; never expose them to fundraisers or unassigned users.
- Apply schema updates additively, preserve records, and document operational
  migration steps. Verify permission isolation, persistence and all three locales.
